# OrbitNode

OrbitNode is a high-performance, cloud-based platform that utilizes auto-scaling to serve as a scalable orchestrator for complex systems.

OrbitNode is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OrbitNode.git`
2. `cd OrbitNode`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
